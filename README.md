## 🧾 Task Service

**Task Service** — микросервис управления задачами в составе микросервисной платформы форума.
Сервис отвечает за создание, обновление и обработку задач, а также за асинхронную фоновую обработку с использованием очередей сообщений. Взаимодействие с другими сервисами осуществляется через **Kafka**, а выполнение длительных операций выносится в **Celery**.

Task Service является частью проекта **[Microservices_Site](https://github.com/Weit145/microservices_site)**.

### 🔧 Зона ответственности

* создание, обновление и управление задачами;
* обработка бизнес-логики задач;
* постановка задач в очередь сообщений;
* взаимодействие с **RabbitMQ**;
* асинхронная фоновая обработка через **Celery Worker**;

### 🚀 Технологический стек и зависимости

| Компонент                        | Назначение                            |
| -------------------------------- | ------------------------------------- |
| **Python**                        | Основной язык разработки              |
| **RabbitMQ**                     | Брокер сообщений для очередей задач   |
| **Celery**                       | Асинхронная обработка фоновых задач   |
| **Poetry**                       | Управление зависимостями и окружением |
| **Docker**                       | Контейнеризация и деплой              |
| **aiokafka**                     | Публикация/подписка на события Kafka  |


### 🧩 Взаимодействие в системе

* публикует и/или потребляет события через Kafka;
* использует **RabbitMQ** для постановки задач в очередь Celery;
* работает в связке с отдельным сервисом **Celery Worker**;
* не имеет прямого HTTP-доступа извне.


### 🛡️ Безопасность и примечания

* Вся логика постановки и обработки задач централизована в Task Service.
* Сервис масштабируется независимо от других компонентов системы.
